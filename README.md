<h1>Stock Price Prediction Using Linear Regression</h1>

This project demonstrates a simple stock price prediction model using historical closing prices and linear regression. The dataset is generated inside the script and contains 10 days of stock prices starting from January 1, 2024.

**What the project does**

Creates a small sample dataset of dates and closing prices

Converts dates into ordinal numbers so they can be used in a machine learning model

Splits the data into training and testing sets

Trains a Linear Regression model to learn the relationship between date and price

Evaluates the model using Mean Squared Error (MSE) and R² Score

Plots actual vs predicted stock prices

Predicts the stock price for a future date (January 11, 2024)

**Technologies Used**

Python

Pandas

Scikit‑learn

Matplotlib

**Output**

The script prints:

The first few rows of the dataset

Model performance metrics (MSE and R²)

A plot comparing actual vs predicted prices

The predicted price for a future date
